# Yau Contest

本专题是一套从大学数学起点讲起的数学讲解手册。默认读者已经熟练掌握高中阶段的实数运算、代数恒等变形、方程与不等式、指数与对数、数列、平面解析几何、基础函数和一元导数运算；这些内容不重复证明。不默认读者学过大学线性代数、实分析、多元微积分或数值分析。大学层面的概念必须先定义，使用到的定理必须给出证明或明确列为本书采用的基础公理。

## 内容范围与约定

本阶段只建立四条相互连接的主线：

1. 矩阵、范数、特征值与谱半径；
2. 正交投影、奇异值分解（Singular Value Decomposition，SVD）与最小二乘（least squares）；
3. 线性迭代、不动点迭代（fixed-point iteration）与压缩映射（contraction mapping）；
4. 泰勒定理（Taylor theorem）、牛顿法（Newton's method）与收敛阶（order of convergence）。

正文中的重要术语第一次出现时给出英文标准名称。证明中使用的记号遵守以下约定：

- 标量用小写字母，如 $a,x,\lambda$；
- 向量默认是列向量，如 $x\in\mathbb R^n$；
- 矩阵用大写字母，如 $A\in\mathbb R^{m\times n}$；
- $A^T$ 表示转置，$I_n$ 表示 $n$ 阶单位矩阵；
- $\ker(A)$、$\operatorname{Col}(A)$ 分别表示零空间和列空间；
- 除非另行说明，向量范数是欧几里得范数（Euclidean norm）$\|x\|_2$，矩阵范数是与它诱导的算子范数（operator norm）$\|A\|_2$。

## 定理阅读方法

阅读每个定理时固定做四件事：

1. 圈出对象，例如“非空完备度量空间”或“实对称矩阵”；
2. 标记每个假设，例如“$f'(\alpha)\ne0$”不能省略；
3. 分开结论，例如存在、唯一、算法收敛是三个命题；
4. 检查反例，确认删去哪条假设会失败。

例如 $\rho(B)<1$ 与 $B^k\to0$ 是等价命题，但 $\rho(B)<1$ 与 $\|B\|_2<1$ 并不等价。后者是更强的充分条件。手册会反复区分这种逻辑强弱。

## 公式阅读方法

遇到公式先检查尺寸，再做代数。例如

$$
A\in\mathbb R^{m\times n},\qquad x\in\mathbb R^n,
$$

则 $Ax\in\mathbb R^m$、$A^TA\in\mathbb R^{n\times n}$、$AA^T\in\mathbb R^{m\times m}$。维数检查能够在计算开始前排除大量错误。

对于极限或误差式，还要说明趋近过程。写 $o(e_k^2)$ 时隐含 $e_k\to0$；写 $B^k\to0$ 时应说明矩阵收敛是在任意等价矩阵范数下成立。

## 章节学习顺序

每章按同一方式使用：

1. 先手算定义后的第一个例子；
2. 再阅读定理证明，并在纸上补全等号之间的理由；
3. 检查反例，确认定理条件不是装饰；
4. 最后完成章末练习，再进入下一章。

专题的完成标准是：能够从定义重新推出结论，并能说明每一步为何成立。
