# Repeated Games & Learning

一次博弈只看当前收益，重复互动则让**历史和未来后果**进入今天的决策。同一个静态博弈，重复以后可能产生完全不同的行为。

## 历史依赖策略

玩家不再只选择“合作/背叛”，而可以使用规则：“如果对方过去合作，我继续合作；如果它背叛，我改变策略。”

因此历史本身成为策略输入。

## 未来越重要，当前行为越可能考虑长期关系

常用折扣因子 $\delta\in[0,1)$ 表示对未来收益的重视程度：

$$
U=\sum_{t=0}^{\infty}\delta^t u_t.
$$

$\delta$ 越大，未来惩罚或未来合作收益越重要。一次性占便宜可能不再值得。

## 重复不等于一定产生合作

合作能否维持还取决于行为是否可观察、互动是否足够长期、惩罚是否可信。若玩家知道下一轮就是最后一轮，激励结构可能再次发生变化。

因此不要把“重复博弈支持合作”误解成“多玩几轮自然会合作”。

## 学习规则描述玩家怎样根据经验调整策略

玩家可能根据历史频率形成对手模型，也可能使用 regret-based 更新或强化学习。学习动态告诉我们策略怎样变化，而 Nash 均衡告诉我们某个策略组合是否稳定。

这两个问题相关，但不能混为一谈。

## 稳定收益不代表已经收敛到某个均衡

仿真中几条收益曲线变平，可能只是学习率变小、策略陷入循环或探索减少。要声称达到某类均衡，需要检查相应的偏离收益或 exploitability，而不是只看 reward 不再变化。

## 对工程系统最重要的是历史会改变对手

多智能体在线学习时，对手或队友也会根据过去互动更新策略，因此环境会随学习而改变。重复博弈提供了理解这种长期相互适应的基本视角。

## 实验里最好检查单边偏离还能赚多少

如果要判断一个稳定策略是否接近均衡，可以固定其他玩家策略，让某个玩家单独搜索更好的响应。如果它还能显著提高收益，当前策略组合就仍然可被利用。

这比单纯观察 reward 曲线是否变平，更接近均衡定义本身。

## 把一次收益和长期关系分开

重复博弈中，当前动作既产生即时收益，也改变对手对未来的预期。折扣因子越高，未来惩罚或合作回报越重要。分析实验结果时，应同时记录短期收益、策略变化和对历史的响应，否则无法判断合作来自激励结构还是偶然同步。
