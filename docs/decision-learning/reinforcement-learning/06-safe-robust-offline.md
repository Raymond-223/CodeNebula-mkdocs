# Safe, Robust & Offline RL

> 普通游戏里，智能体撞墙一万次也只是训练慢；真实机器人如果把“撞墙”当探索动作，第一次就可能损坏设备。再进一步，部署环境可能和训练时不同，而且你手里也许只有一批固定日志，不能继续自由采样。
>
> 这三个限制分别逼出 safe、robust、offline RL。先看“哪些动作根本不允许试、环境变化多少、还能不能采新数据”，再选算法，才不会把三个不同问题混成“训练更稳”。

## 在线试错的风险边界

先统一符号：$\pi$ 是待学策略，$\pi_\beta$ 是产生数据的行为策略，$J(\pi)$ 是期望折扣回报，$J_C(\pi)$ 是期望折扣累计成本，$d$ 是成本预算，$N$ 是允许的交互步数。

在线 RL 的隐含前提是“交互风险可以被承受并统计”。设每次交互发生危险事件的概率为 $p_{\text{fail}}$，一旦发生造成损失 $c_{\text{fail}}$，并暂时假设各次风险相同，则进行 $N$ 次交互的**期望损失**为 $Np_{\text{fail}}c_{\text{fail}}$。若期望风险预算为 $B$，只能推出

$$N \le \frac{B}{p_{\text{fail}}c_{\text{fail}}}.$$

这个式子不是逐次安全保证：即使期望损失不超预算，第一次交互仍可能出事。若危险事件不可接受，必须施加“每一步都满足约束”的硬安全条件，而不能把事故成本平均掉。样本复杂度也依赖算法、MDP 类别、视界与置信度，不能脱离这些条件断言一个统一次数；真正的矛盾是“学习需要覆盖足够多的状态—动作，而真实系统可承受的危险交互很少”。

边界的形状取决于失败是否可逆。可逆失败（撞到软性障碍、电量耗尽后返回充电）可以计入 $B$；不可逆失败（撞人、结构损伤）必须让 $N_{\text{safe}}$ 直接取 0，此时问题从"少试几次"变成"根本不许试"，也就是必须转成 Offline 或 Safe 的形式化。

| 限制来源 | 数学对象 | 被违反时的典型失效 |
|---|---|---|
| 动作代价不可忽略 | 约束 MDP 的成本函数 $c(s,a)$ | 策略回报很高但频繁越界 |
| 交互预算受限 | 固定的数据集 $D$，无新样本 | 价值估计在数据外被系统性高估 |
| 环境参数会漂移 | 不确定集 $\mathcal P$ 上的 minimax | 换工况后回报断崖式下跌 |
| 观测被噪声污染 | $o = s + \epsilon$，$\|\epsilon\|\le \epsilon_{\max}$ | 训练环境正常、现场决策抖动 |
| 评估无法在线验证 | 重要性权重比率 $\pi/\pi_\beta$ | 离线指标漂亮，上线回归 |

## 离线强化学习（Offline RL）与数据分布

Offline RL 的输入只有一个固定的 $(D)$，$D=\{(s_t,a_t,r_t,s'_{t})\}_{t=1}^{N}$，由未知的行为策略 $\pi_\beta$ 生成。定义行为策略的折扣占用度量

$$d^{\pi_\beta}(s,a) = (1-\gamma)\sum_{t=0}^{\infty}\gamma^{t}\, \mathbb P\big(s_t=s, a_t=a \mid \pi_\beta\big).$$

Offline RL 想解的目标是在**分布约束**下的回报最大化：

$$\max_\pi\; J(\pi)\quad \text{s.t.}\quad D_{\mathrm{TV}}\big(d^{\pi} \,\|\, d^{\pi_\beta}\big)\le \epsilon .$$

另一类常用但**并不等价**的约束是限制占用度量的密度比。例如要求在 $d^{\pi_\beta}(s,a)>0$ 处

$$\frac{d^\pi(s,a)}{d^{\pi_\beta}(s,a)}\le M.$$

策略比 $\pi(a\mid s)/\pi_\beta(a\mid s)$ 只比较同一状态下的动作概率，遗漏了目标策略改变后产生的状态分布漂移；因此它不能替代占用度量比。$M=1$ 与两个占用度量都归一化合起来才迫使二者相等；$M$ 变大只是放宽这一约束，并不自动提供分布外可验证性。

约束的必要性来自覆盖的稀疏性。设 $D$ 有 $N=10^6$ 条转移，离散化后有 $|\mathcal S|\times|\mathcal A| = 10^{8}$ 个格子，则平均每格只有 $10^{-2}$ 条样本，绝大多数格子上是空的。**任何在这些空格上取 $\max$ 的价值目标，都是在用零证据做决策。**

| 数据分布特征 | 可安全学习的对象 | 不能声称的结论 |
|---|---|---|
| 覆盖广、$\pi_\beta$ 熵高 | 接近 $J(\pi_\beta)$ 的策略、局部改进 | 全局最优性 |
| 覆盖窄但集中在目标工况 | 该工况下的精细策略 | 工况外泛化 |
| 多行为策略混合 | 数据整合、加权价值估计 | 单策略可比性 |
| 含安全关键轨迹极少 | 成本函数上界、风险区域刻画 | 约束可行性保证 |
| 纯日志、无探索噪声 | 数据支持区域内的行为拟合 | 未经覆盖假设证明的回报下界或策略改进 |

## 鲁棒性与扰动

鲁棒 RL 承认"训练时的动力学不是唯一可能的动力学"。设转移分布属于一个不确定集 $\mathcal P$，鲁棒目标是

$$\max_\pi \; \min_{P\in\mathcal P}\; \mathbb E_{\tau\sim(\pi,P)}\left[\sum_{t=0}^{T}\gamma^{t} r(s_t,a_t)\right].$$

内层 $\min$ 把环境当成对手，让策略在网络攻击或工况漂移下也成立。$\mathcal P$ 的三种常见构造：

- **参数扰动**：$P_{\theta}$ 且 $\|\theta-\theta_0\|_2\le \rho$，$\rho$ 是半径，$\rho=0$ 退化为名义 MDP。
- **观测扰动**：$o = s + \epsilon$，$\|\epsilon\|_2 \le \epsilon_{\max}$，考察策略对状态估计误差的敏感性。
- **动作扰动**：实际执行 $a = \pi(s) + \delta$，模拟执行器死区、通信丢包造成的动作偏差。

代价是“鲁棒性价格”（price of robustness）：不确定集扩大时，可保证的最坏情形性能不会提高，而名义性能也可能下降。下降多少取决于动力学、集合形状和策略类，不能用固定百分比概括。扩大不确定集是把更多模型纳入防御范围，而不是把真实状态“排除在可信区域之外”；集合若大得不符合实际，最优策略会为不可能出现的模型付出过度保守的代价。

| 扰动类型 | 建模方式 | 典型防御 | 过度防御的后果 |
|---|---|---|---|
| 转移参数漂移 | 集合 $\|\theta-\theta_0\|\le \rho$ | minimax / 对抗训练 | 名义性能大幅下降 |
| 观测噪声 | $\|o-s\|\le \epsilon_{\max}$ | 状态估计滤波、观测对抗训练 | 反应迟钝、错过机会窗口 |
| 动作执行偏差 | $a = \pi(s)+\delta$ | 平滑动作、低增益控制器 | 收敛慢、任务超时 |
| 奖励函数变化 | $r\in\{r_1,\dots,r_k\}$ | 多目标 / 逆 RL | 目标混淆、无法收敛 |
| 对手主动攻击 | 双层博弈 | 博弈论均衡求解 | 假设过强导致空解 |

## 约束马尔可夫决策过程（CMDP）与约束优化

这是 Safe RL 的标准形式化。在 MDP 上增加成本函数 $c:\mathcal S\times\mathcal A\to[0,c_{\max}]$ 与预算 $d$，得到约束 MDP（CMDP），其联合目标写成

$$\max_\pi\; J(\pi) = \mathbb E_{\tau\sim\pi}\!\left[\sum_{t}\gamma^{t} r(s_t,a_t)\right] \quad \text{s.t.}\quad J_C(\pi) = \mathbb E_{\tau\sim\pi}\!\left[\sum_{t}\gamma^{t} c(s_t,a_t)\right] \le d .$$

注意 $d$ 是**折扣累计成本**的预算，不是瞬时每步的约束。若过程已进入稳态，且每步平均成本为 $\bar c$，则

$$J_C=\sum_{t=0}^{\infty}\gamma^t\bar c=\frac{\bar c}{1-\gamma}.$$

所以 $\gamma=0.99,d=1$ 对应 $\bar c\le(1-\gamma)d=0.01$。若一次事故的成本为 1、其他时刻成本为 0，这相当于长期平均约每 100 步至多一次事故，而不是“百万步一次”。该换算还依赖稳态平均的解释；它不是逐时刻硬安全保证。

直接带约束的梯度更新很别扭，标准做法是拉格朗日松弛。引入对偶变量 $\lambda\ge 0$：

$$\mathcal L(\pi,\lambda) = J(\pi) - \lambda\big(J_C(\pi) - d\big),$$

定义对偶函数 $g(\lambda)=\max_\pi \mathcal L(\pi,\lambda)$。对任意 $\lambda\ge0$ 和任意可行策略，都有 $\mathcal L(\pi,\lambda)\ge J(\pi)$，故弱对偶给出

$$J^{\star} \le \inf_{\lambda\ge0} g(\lambda).$$

只有在满足强对偶所需条件时才能把不等号写成等号。例如有限折扣 CMDP 改用占用度量作变量后是线性规划；若原问题可行，线性规划强对偶可用。直接用神经网络参数化策略时问题一般非凸，不能无条件声称强对偶。

对偶变量的更新规则是次梯度的投影形式：

$$\lambda_{k+1} = \max\!\big(0,\; \lambda_k + \eta_\lambda\big(J_C(\pi_k) - d\big)\big).$$

这就是"保守程度自动调节"的全部机制：把 $J_C(\pi_k) > d$ 解释为"成本超支"，于是 $\lambda$ 上升，等价奖励变为 $r - \lambda c$，成本项的权重被放大，策略被推向低风险动作；反之 $J_C(\pi_k) < d$ 时 $\lambda$ 下降直至 0，约束失去作用，退化成普通 RL。$\eta_\lambda$ 决定调节速度：太大则 $\lambda$ 在 0 与高值之间震荡、策略来回摇摆；太小则超支状态会持续很久。

| $\lambda$ 所处区间 | 有效奖励 $r-\lambda c$ 的含义 | 策略行为 | 需要警惕 |
|---|---|---|---|
| $\lambda = 0$ | 当前拉格朗日目标不惩罚成本 | 可能追求更高回报 | 约束可能松弛，也可能恰好活跃；不能仅凭 $\lambda=0$ 判断 |
| $\lambda$ 适中 | 风险与回报真正权衡 | 在预算边界附近工作 | 收敛慢、方差大 |
| $\lambda \to \lambda^{\star}>0$ | 在满足 KKT 条件时，互补松弛迫使约束取等号 | 常在 $J_C=d$ 附近工作 | 对成本估计误差敏感 |
| $\lambda$ 过大 | 成本项压倒奖励 | 极端保守、原地不动 | 任务完全不可用 |

工程上有两个常见坑：一是成本估计本身来自数据，若 $J_C$ 被低估，$\lambda$ 会在错误信号下"以为已经安全"；二是深度 RL 的 primal 与 dual 用不同学习率，$\eta_\lambda$ 与策略步长的比例会决定系统稳定性，实践中通常对 $\lambda$ 做裁剪 $\lambda\le \lambda_{\max}$，并让 $\eta_\lambda$ 显著小于策略学习率。

## 外推误差与保守性

Offline RL 最核心的技术危险是**分布外动作的 Q 值被系统性高估**，而这个高估不是简单的"网络过拟合噪点"，它有确定的数学来源。

设 $\hat Q$ 是估计器。TD 目标里的 $\max$ 算子作用在一个带噪声的函数上：

$$\mathbb E\Big[\max_{a'}\hat Q(s',a')\Big] \;\ge\; \max_{a'}\mathbb E\big[\hat Q(s',a')\big].$$

这是 Jensen 不等式 + 凸函数的直接结果：**即使 $\hat Q$ 在每个点上都无偏，取 max 也会得到正偏差。**在线 RL 中这个偏差会被后续真实采样纠正——选了高估的动作，环境马上返回一个更低的真实回报；离线时这个纠正通道被彻底切断，$D$ 中根本没有对应的 $s'$ 与后续数据，高估就被存储在值函数里并沿 Bellman 备份向回传播：

$$\hat Q(s,a) \leftarrow r + \gamma \max_{a'}\hat Q(s',a').$$

单步误差 $\varepsilon$ 在折扣累积后放大 $\sum_{t}\gamma^{t} = \frac{1}{1-\gamma}$ 倍：$\gamma=0.99$ 时放大约 100 倍，$\gamma=0.999$ 时约 1000 倍。**这就是离线回报估计动辄虚高一个数量级的来源。**

抑制手段统称悲观原则（pessimism）：在无数据支持的 $(s,a)$ 上主动压低价值，

$$\hat Q_{\text{pes}}(s,a) = \hat Q(s,a) - \beta\, u(s,a),$$

$u(s,a)\ge0$ 是不确定性度量，常用集成网络方差、密度比倒数 $1/\hat\pi_\beta(a\mid s)$，或 ensemble 成员分歧。CQL 的等价实现把惩罚直接嵌进目标：

$$\min_Q\; \alpha\;\mathbb E_{s\sim D}\left[\log\sum_{a}\exp Q(s,a) - \mathbb E_{a\sim\hat\pi_\beta}\big[Q(s,a)\big]\right] + \mathcal L_{\text{TD}}(Q).$$

括号内第一项把所有动作的 Q 值往上推，第二项把数据中真实出现过的动作往上推——两者相减，净效果是**把未见动作相对已见动作压低**。

| 保守程度 | 机制层面的表现 | 上层可观测的失效 |
|---|---|---|
| 惩罚不足 $\alpha\ll$ 合适值 | OOD 动作 Q 值虚高、被策略选中 | 离线指标虚高，上线立刻打脸 |
| 惩罚略强 | 策略只在数据密集区改进 | 改进幅度小于预期，但基本安全 |
| 惩罚过强 | 策略被压回 $\hat\pi_\beta$ 附近 | 回报 $\approx J(\pi_\beta)$，学了个"最贵的模仿" |
| 惩罚各向同性、不看支撑集 | 数据密集区也被惩罚 | 明明有大量样本也不改进 |
| 惩罚只看状态不看动作 | 状态被访问过就认为安全 | 对同一状态下罕见动作仍然高估 |

中间两行是这门技术的真正困境：**做保守防住分布外高估，做太保守则连分布内的改进机会一起抹掉。**判断标准不是"有没有惩罚"，而是"惩罚是否与数据支撑密度成反比"——$u(s,a)$ 应当只对该 $(s,a)$ 的样本量不足时显著，而不是全局抬高。

## 安全约束与风险

约束有"期望形式"和"风险形式"两层，混用会造成安全检查通过、现场仍然出事。

期望形式就是上一节的 $J_C(\pi)\le d$，它约束的是**平均**成本。若 $d=0.01$（每步允许 1% 单位成本），一个 1% 概率发生严重事故、99% 概率完全安全的策略可以通过检验。风险形式可用条件在险价值（CVaR）约束尾部。对“损失越大越坏”的随机变量 $Z$，一个对离散分布和存在概率原子也适用的定义是

$$
\operatorname{CVaR}_\alpha(Z)
=\min_{\eta\in\mathbb R}\left\{\eta+\frac{1}{1-\alpha}\,\mathbb E[(Z-\eta)_+]\right\}
\le d_{\text{tail}},
\qquad (x)_+=\max\{x,0\}.
$$

在分布连续且 $\mathbb P(Z=\operatorname{VaR}_\alpha(Z))=0$ 时，它才可简写为 $\mathbb E[Z\mid Z\ge\operatorname{VaR}_\alpha(Z)]$。$\alpha=0.95$ 表示平均最坏约 $5\%$ 的损失；$\alpha$ 越接近 1，约束越集中于极端尾部，对样本量的要求也越高。

运行时层使用控制屏障函数（CBF）。给定安全集 $\{s: h(s)\ge 0\}$，只要存在控制量使

$$\dot h(s) + \alpha\, h(s) \ge 0,\qquad \alpha>0,$$

就能保证 $h$ 不会穿零（前向不变性）。把它做成动作过滤器：RL 给出 $a_{\text{rl}}$，安全层投影到可行集

$$a_{\text{safe}} = \arg\min_{a\in\mathcal A_{\text{safe}}(s)} \|a - a_{\text{rl}}\|.$$

| 约束形式 | 语义 | 何时不足 |
|---|---|---|
| 期望成本 $J_C\le d$ | 长期平均不超预算 | 允许低概率极端事故 |
| 硬状态约束 $\|h\|$ 不越界 | 逐时刻不进入禁区 | 需要精确的 $h$ 与模型 |
| CVaR 尾部约束 | 最差 $\alpha$ 分位受控 | 事故样本稀少、分位数不可估 |
| 概率约束 $\mathbb P(\text{失败})\le \delta$ | 失败概率有界 | 需要已知分布或大量样本 |
| 运行时过滤 / shield | 动作级兜底 | 过滤器本身错误即失去保护 |

**分层是必要的：训练时用 CMDP 塑形，运行时用 CBF 兜底。**只做前者，估计误差会在边缘场景致命；只做后者，策略本身可能长期贴着约束边界运行，任何一点模型误差都会让它越界。

## 三类问题不要混在一起

三个问题有各自可区分的诊断信号，误判会导致把预算花在错误的改造上。

| 问题来源 | 诊断信号（先问这句） | 正确改造方向 | 误判后的后果 |
|---|---|---|---|
| Offline | 能不能继续采样？ | 改数据覆盖、加悲观惩罚、密度比约束 | 在空数据区"优化"，回报虚高 |
| Robust | 换了工况还成立吗？ | 扩不确定集、minimax 目标、域随机化 | 只优化单一工况，漂移即崩 |
| Safe | 有没有绝不允许的状态？ | 加成本函数、CVaR、运行时过滤层 | 拿平均收益代替硬约束 |

三者叠加时约束会相乘式收紧，这一点必须显式记账。以"离线 + 鲁棒 + 安全"为例，要同时满足在 $D$ 支撑集内、对所有 $P\in\mathcal P$、且 $J_C\le d$，可行策略集是三个集合的交：

$$\Pi_{\text{feasible}} = \underbrace{\{\pi: d^{\pi}\preceq M d^{\pi_\beta}\}}_{\text{offline}} \;\cap\; \underbrace{\{\pi: \forall P\in\mathcal P,\; J_{P}(\pi)\ge J_{\min}\}}_{\text{robust}} \;\cap\; \underbrace{\{\pi: J_C(\pi)\le d\}}_{\text{safe}} .$$

交集很容易是空集——数据覆盖不足、又要对所有扰动成立、还要满足硬约束，可能根本不存在这样的策略。此时诊断结论不是“算法不够好”，而是**问题设定本身不可行**，正确动作是重新检查预算、数据覆盖与不确定集。样本复杂度取决于模型类容量、不确定集结构、误差容许度和置信度；没有附加假设时不存在统一的 $\rho^{-2}$ 乘法规律。

## 离线强化学习（Offline RL）的分布外风险

把上一节的机制落到可操作的判据。"分布外动作"指的是目标策略给出显著概率、而 $\pi_\beta$ 几乎不给概率的动作集合：

$$\mathcal A_{\text{OOD}}(s) = \big\{a : \pi(a\mid s) > \delta,\; \hat\pi_\beta(a\mid s) < \epsilon \big\}.$$

若 $\mathcal A_{\text{OOD}}\neq\varnothing$，说明目标策略把显著概率放到了行为数据很少支持的动作上；此处的 Q 值通常只能依赖函数外推。是否“完全无数据”还要看有限样本计数、连续空间邻域以及函数类假设，不能由两个阈值直接推出。

高风险场景可以被分解。单步支持不足 $\to$ 该步 TD 误差不可控；Bellman 备份 $\to$ 误差向状态空间上游传播；目标里的 $\max$ $\to$ 主动挑选高估动作。三者叠加形成闭环，这也解释了为什么朴素 Q-learning 在离线数据上会得到"漂亮但假"的曲线。

| 离线训练中的现象 | 背后机制 | 可以作为预警的征兆 |
|---|---|---|
| 离线回报估计持续上升 | OOD 动作 Q 值被 max 选中 | 估计回报超过数据中最高轨迹回报 |
| 策略动作越来越极端 | 密度比 $\pi/\pi_\beta$ 增大 | 损失里的 $\log$ 比项持续变大 |
| 训练后期突然崩坏 | 误差被 $\frac{1}{1-\gamma}$ 放大到发散 | TD 误差出现数量级跳变 |
| 上线表现随部署时长衰减 | 状态分布逐渐漂出数据集 | 实际访问状态的密度比升高 |
| 换随机种子结果差异巨大 | 高估区域随机 | 多随机种子离线指标方差极大 |

一个实用的纪律：**离线训练期间就监控策略动作相对数据集的概率之比，而不是只看回报曲线。**密度比分位数（如 $95\%$ 分位的 $\pi/\pi_\beta$）从 1 涨到 100，说明策略已经进入了不能被验证的区域，此后所有回报数字都只是外推。

## 鲁棒、安全和离线分别解决不同问题

把三者当成同一个词，就会写出"我们把模型做鲁棒了所以不怕安全问题"这种无法执行的结论。它们的差别在于**不确定性被假设成什么**：

| 维度 | Offline | Robust | Safe |
|---|---|---|---|
| 不确定性来源 | 数据覆盖（哪些 $(s,a)$ 有样本） | 环境参数 / 噪声（$\theta,\epsilon$） | 约束可行性（是否越界） |
| 数学形式 | 支撑集约束下的 $\max J$ | $\max_\pi\min_{P\in\mathcal P}$ | $\max J$ s.t. $J_C\le d$ |
| 失败表现 | 回报虚高、上线掉分 | 换工况后性能崩 | 高频越界、事故 |
| 主要杠杆 | 数据覆盖、悲观惩罚 | 不确定集 $P$、对抗训练 | 成本函数、$\lambda$、过滤层 |
| 验证方式 | 离线代理指标 + 多随机种子 | 扰动测试、域随机化评测 | 约束满足率、CVaR 统计 |
| 简单判据 | 能不能再采样 | 环境会不会变 | 有没有绝对禁区 |

一个具体例子可以一次区分三者：用六个月历史日志训练仓储 AGV 是 Offline；地面摩擦系数、载重分布会随季节和批次变化是 Robust；车体绝不能进入人员工作区是 Safe。三条改造路径互不替代：扩大数据集不解决约束，加约束不解决摩擦漂移，域随机化也不解决"数据里根本没有那种动作"。

## 离线评估的困难

离线 RL 最容易被低估的环节是评估。**策略改进需要验证，而验证需要环境交互——这个前提在离线设定下恰好被剥夺。** $J(\pi)$ 的真值不存在于任何数据中，它是关于反事实轨迹的期望。

最直接的想法是重要性采样（IS）。用数据集轨迹 $i$ 的回报 $G_i$ 做加权：

$$\hat J_{\text{IS}}(\pi) = \frac{1}{N}\sum_{i=1}^{N} \left(\prod_{t=0}^{T-1}\frac{\pi(a_{t}^{i}\mid s_{t}^{i})}{\pi_\beta(a_{t}^{i}\mid s_{t}^{i})}\right) G_i .$$

方差可能随轨迹长度指数增长。设单步权重 $w=\pi(a\mid s)/\pi_\beta(a\mid s)$，在行为策略分布下

$$\mathbb E_{\pi_\beta}[w^2]=\exp\!\left(D_2(\pi\|\pi_\beta)\right),$$

其中 $D_2$ 是二阶 Rényi 散度，不是 $2D_{\mathrm{KL}}$。若再假设各步权重独立同分布，轨迹权重二阶矩才会成为这个量的 $T$ 次方；真实 MDP 中各步相关，不能直接写成等号。

取每步权重比恒为 2、$T=50$ 步，轨迹权重是 $2^{50}\approx 10^{15}$——实际效应是权重可能被极少数轨迹垄断。对非负且不全为零的权重，$\mathrm{ESS}=(\sum_iw_i)^2/\sum_iw_i^2$ 位于 $[1,N]$；接近 1 表示几乎只剩一条有效轨迹。per-decision IS 可缓和乘积长度，WIS 归一化通常降低方差但引入有限样本偏差。

| 代理指标 | 能回答的问题 | 主要局限 |
|---|---|---|
| FQE（拟合 Q 评估） | $\pi$ 相对 $\pi_\beta$ 的近似回报 | 会继承同一批 OOD 分区的估计误差 |
| 普通重要性采样 IS | 在支持条件与正确行为概率下无偏 | 方差可随 $T$ 急剧增长，ESS 极低 |
| 自归一化重要性采样 WIS | 常降低方差且数值稳定 | 有限样本下一般有偏，但可在条件下渐近一致 |
| 模型 rollout 评估 | 多步反事实轨迹 | 模型误差被 $\frac{1}{1-\gamma}$ 倍放大 |
| OOD 动作占比 | 策略是否落在支撑集内 | 只是必要条件，不能给回报数值 |
| 行为策略回报 $J(\pi_\beta)$ | 数据收集策略的基线回报 | 既不是目标策略回报，也不构成其一般下界 |
| 多随机种子离散度 | 估计是否稳定 | 稳定不保证正确，可能一起错 |

实务上的最低要求是**同时报告至少两类互相独立的代理指标**：一类给数值（如 FQE），一类给可信区间（如 OOD 动作占比、密度比分位数）。若前者很高而后者显示策略经常落在数据支撑集外，结论应当被判定为不可用，而不是"有待线上验证"——离线设定里没有这次验证的机会。

## 数据覆盖决定离线结论

最后一节的结论可以压缩成一句话：**离线 RL 的结论永远是条件命题，条件是数据集的支撑集。**形式化地，任何关于 $\pi$ 的回报声明都必须附带覆盖范围：

$$
\mathbb P_{(s,a)\sim d^\pi}
\big[\hat\pi_\beta(a\mid s)<\epsilon\big]\le\delta.
$$

这里动作 $a$ 与状态 $s$ 一起按目标策略的占用度量采样。该式只是一个覆盖诊断量；要把它变成“评估可信”的充分条件，还需控制行为策略估计误差、重要性权重尾部、样本相关性与回报界。

这个概率就是"策略落在数据支撑集之外的比例"。它可以直接从 $D$ 上训练的密度模型估计出来，不需要任何环境交互。

需要报告的三个量：(1) 行为策略的动作熵 $H(\pi_\beta(\cdot\mid s))$，低熵意味着数据只覆盖少数模式；(2) 目标策略与行为策略的密度比 $95\%$ 分位数，衡量策略偏离幅度；(3) 数据中安全关键区域的样本数，它决定任何约束声明是"有证据"还是"纯假设"。

| 数据特征 | 可信的结论上限 | 必须放弃的声明 |
|---|---|---|
| 单一行为策略、窄覆盖 | $\pi$ 与 $\pi_\beta$ 的局部对比 | 最优性、跨工况泛化 |
| 多策略混合、广覆盖 | 在支撑集内的策略改进 | 支撑集外的安全性 |
| 含少量安全关键样本 | 风险区域的粗略刻画 | 尾部概率的定量保证 |
| 无任何越界样本 | 约束基本无用（无可学信号） | 任何"已满足约束"的结论 |

因此，离线项目的正确起点不是选算法，而是先量化数据覆盖，再决定允许声称什么级别的结论；算法只决定在这个上限之内能逼近多少。
