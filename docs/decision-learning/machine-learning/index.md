# Machine Learning Foundations

> 这一部分补齐后续 RL、视觉和多模态感知真正会用到的机器学习前置。训练机制与网络结构分开讲，避免在一章里同时压入反向传播、CNN、RNN 和 Transformer。

学习顺序：

1. [Machine Learning Training Basics](01-ml-neural-network-basics.md)：数据、损失、训练/验证、两层网络反向传播与正则化；
2. [Neural Network Architectures](02-neural-network-architectures.md)：卷积、循环状态、Attention 与 Transformer 的逐步计算；
3. 再进入 Reinforcement Learning 或 Perception。
