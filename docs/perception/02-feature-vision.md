# 特征视觉

在深度网络普及以前，视觉系统常通过“找到稳定局部点 → 描述它们 → 在不同图像中匹配”来建立几何关系。这个思想今天仍然是理解视觉里程计、SLAM 和图像配准的重要基础。

## 好的特征点必须能被重复找到

角点、纹理明显的局部结构比大面积纯色区域更容易再次检测。所谓 repeatability，就是相机移动、尺度变化或轻微光照变化后，同一个真实位置仍能产生对应特征。

如果一帧检测到的点下一帧完全找不到，再复杂的描述子也无法建立运动关系。

## 描述子把局部图像变成可以比较的向量

检测只回答“哪里值得看”，描述子进一步回答“这个局部区域长什么样”。SIFT、ORB 等方法会把局部纹理编码成向量或二进制模式，匹配时比较描述子距离。

因此经典特征管线可以记成：

**detect → describe → match**。

## 候选匹配与几何验证

重复纹理、运动模糊和动态物体都会产生错误匹配。两个描述子很像，并不保证它们来自同一个真实三维点。

实际系统会利用单应矩阵、基础矩阵或相机运动模型检查几何一致性。RANSAC 的作用就是在含有离群点的候选匹配中反复抽样，寻找得到多数数据支持的模型。

## 特征匹配最终服务的是几何关系

如果两幅图来自同一平面或相机纯旋转，单应矩阵可以描述对应；一般三维场景则会受到 epipolar geometry 约束。入门阶段不必完整推导所有矩阵，但要知道：**匹配不是终点，匹配只是估计相机或物体几何关系的观测。**

## 传统特征什么时候仍然很有价值

在纹理丰富、需要明确几何约束、算力有限的任务中，ORB/SIFT 仍然十分实用。它们解释性强、调试时可以直接画匹配点，而且不依赖大量训练数据。

弱纹理、强光照变化和大视角变化下，学习型特征往往更稳。但无论描述子由规则还是网络产生，“检测稳定结构 → 建立对应 → 几何验证”这条逻辑不变。

## 匹配质量评估

100 个匹配点并不一定比 30 个更好；如果其中一半是错误对应，位姿估计会被严重破坏。评估匹配质量时更应看几何内点比例、空间分布以及是否集中在动态物体上。

## 特征退化场景

白墙、重复栅栏、强运动模糊、镜面反射都会让特征检测或匹配失效。此时继续调距离阈值通常不能从根本上解决问题。

更有效的思路是引入其他几何来源、增加纹理、降低运动速度，或使用对该场景更鲁棒的学习型表示。先判断数据是否包含足够信息，再谈算法参数。

## 匹配质量的几何判据

好匹配不仅描述子距离小，还应共同支持一个一致的几何模型。可以通过重投影误差、内点比例和空间分布判断匹配是否可靠。大量内点若全部集中在图像一角，也可能无法稳定约束整体运动。
